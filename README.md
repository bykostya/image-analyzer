# Анализ областей на изображении

Небольшое настольное приложение для разметки областей на изображении и расчёта их площади относительно выбранной базы (по умолчанию — всего изображения).

Интерфейс доступен на русском, сербском (латиница) и английском языках. По умолчанию используется русский; язык можно переключить в верхней панели, не теряя текущее изображение и разметку.

## Запуск в Windows

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Если виртуальное окружение ещё не создано:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

## Работа с областями

1. Нажмите **Загрузить изображение** или откройте сохранённый JSON-проект кнопкой **Открыть проект**.
2. Нажмите **Новое выделение (лассо)**: прежняя область снимается с выбора, маркеры её вершин скрываются, а курсор изменится на крестик. Щёлкайте по контуру, чтобы ставить точки; между точками отображаются линии. Как только поставлена третья точка, новая область автоматически появляется в списке и становится выбранной; затем она обновляется по мере рисования. Контур замыкается линией от последней точки к первой и сразу получает полупрозрачную заливку. Двойной щелчок завершает выделение. Незавершённый контур с менее чем тремя точками не сохраняется. Можно также удерживать левую кнопку и обводить область свободной линией.
3. Слева от имени каждой области находится значок глаза: щёлкните его, чтобы показать или скрыть область как слой. Скрытый слой не отображается на холсте и не включается в экспорт изображения; он остаётся в проекте и продолжает участвовать в расчёте площадей. Скрытую область можно снова показать тем же значком. В каждой строке есть отдельный селектор **База**: выберите всё изображение или любую область — процент именно этой строки будет рассчитан относительно выбранной базы. По умолчанию база каждой области — всё изображение; базы независимы друг от друга. Щелчок по тексту строки выбирает область для редактирования; наведение на её контур или вершины не выбирает её. Повторный щелчок по активной строке, клик по пустому месту списка или нажатие **Esc** полностью снимает выбор и скрывает маркеры вершин. Нажатие **Esc** также завершает текущий режим лассо и очищает точки незавершённого контура. Если область не выбрана, кнопки её редактирования и ползунки отключены; при создании новой области она сразу выбирается, и эти элементы активируются. Только у выбранной и видимой области наведение ближе чем на 12 пикселей к вершине магнитно подсвечивает её, а курсор переключается в режим перемещения. Нажмите на подсвеченную точку и, удерживая левую кнопку, перетащите её. Чтобы добавить вершину, выберите область в списке и щёлкните по её границе; новая точка появится на ближайшем ребре. Клик в стороне от границы не меняет контур. Во время рисования можно поправить вершину текущего контура после появления области в списке. Чтобы удалить вершину, сначала выберите видимую область и нажмите **Удалить точку**: приложение перейдёт в режим удаления. Наведите курсор на нужную вершину выбранной области, дождитесь магнитной подсветки и щёлкните левой кнопкой; для выхода нажмите **Отмена удаления**. В области должно оставаться не менее трёх точек.
4. Сумма областей с повторным учётом наложений и объединённая площадь показываются в процентах от всего изображения; эти сводные проценты не зависят от индивидуальных баз в строках списка.
5. Переименуйте область, выберите её цвет, настройте прозрачность заливки и толщину границы. Справа от каждой шкалы отображается её текущее значение с единицей измерения; при переключении области значение обновляется. Чем выше значение прозрачности, тем слабее видна заливка; настройка применяется сразу и сохраняется после завершения лассо. Толщина границы (1–12 px исходного изображения) также применяется сразу и учитывается при экспорте.
6. Сохраните разметку через **Сохранить проект**. JSON хранит путь к исходному изображению (относительно файла проекта, когда возможно), координаты, имена, цвета, прозрачность, видимость, толщину границ, индивидуальную базу процентов и настройки текста для каждой области, DPI и язык. Старые проекты с одной общей базой автоматически переносят её в настройку каждой области. Изображение в JSON не встраивается; при открытии проекта исходный файл должен быть доступен по сохранённому пути.
7. Для экспорта изображения выберите области в окне параметров. Справа отображается крупный предпросмотр результата, который сразу обновляется при смене выбранных областей, параметров пересечений, обрезки и процентных подписей. Скрытые слои отмечены как недоступные и не попадают в экспорт. Можно включить или исключить заливку пикселей пересечений и включить обрезку по общим границам выбранных видимых областей. Фоном результата остаётся исходное изображение; сохраняются исходные пиксели, поверх которых рисуются выбранные области. При включении процентов подписи используют базу соответствующей области, изначально располагаются у верхнего левого края внутри области, а в предпросмотре их можно перетащить левой кнопкой. Размер шрифта выбирается в настройках экспорта; цвет настраивается для каждой области отдельно и по умолчанию совпадает с цветом её контура. Выбранные цвета и перемещённые позиции подписей хранятся в JSON-проекте. Экспорт Excel показывает индивидуальную базу и процент каждой области; сводные проценты рассчитаны относительно всего изображения.

В верхней панели можно переключить язык интерфейса между русским, сербским (латиница) и английским. Созданные названия областей при переключении не меняются; новые области получают название на текущем языке. Заголовки экспортируемой таблицы Excel соответствуют выбранному языку.

Площадь каждой области рассчитывается в пикселях. «С областями» складывает площади всех областей, поэтому наложения считаются несколько раз. «Без наложений» считает площадь объединения, учитывая повторно покрытые пиксели один раз. Если выбранная область-база имеет нулевую площадь, проценты показываются как «—». Экспорт изображения записывает выбранное значение DPI (100, 200, 300, 400, 500 или 600) в метаданные; при включённой обрезке размер результата соответствует выбранным областям с небольшим запасом для отображения границы.

Колесо мыши увеличивает или уменьшает изображение относительно положения курсора. При увеличении используйте горизонтальную и вертикальную полосы прокрутки у холста, чтобы перемещать изображение; также можно зажать правую кнопку мыши и двигать мышь.

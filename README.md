# Анализ областей на изображении

Небольшое настольное приложение для разметки областей на изображении и расчёта их площади относительно выбранной базы (по умолчанию — всего изображения).

Интерфейс доступен на русском, сербском (латиница) и английском языках. По умолчанию используется русский; язык можно переключить в верхней панели, не теряя текущее изображение и разметку.

## Запуск в Windows

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Если виртуальное окружение ещё не создано:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

## Работа с областями

1. Нажмите **Загрузить изображение**.
2. Нажмите **Новое выделение (лассо)**: курсор изменится на крестик. Щёлкайте по контуру, чтобы ставить точки; между точками отображаются линии. Как только поставлена третья точка, область автоматически появляется в списке и затем обновляется по мере рисования. Контур замыкается линией от последней точки к первой и сразу получает полупрозрачную заливку. Двойной щелчок завершает выделение. Незавершённый контур с менее чем тремя точками не сохраняется. Можно также удерживать левую кнопку и обводить область свободной линией.
3. Щелчок по строке области в списке делает её активной; повторный щелчок по этой же строке или нажатие **Esc** снимает выделение и скрывает маркеры вершин. Если область не выбрана, кнопки её редактирования и ползунки отключены; при создании новой области она сразу выбирается, и эти элементы активируются. При наведении ближе чем на 12 пикселей к вершине она магнитно подсвечивается, а курсор переключается в режим перемещения. Нажмите на подсвеченную точку и, удерживая левую кнопку, перетащите её. Во время рисования так можно поправить вершину текущего контура после появления области в списке. Двойной щелчок по границе добавит точку. Чтобы удалить вершину, сначала нажмите **Удалить точку**: приложение перейдёт в режим удаления. Наведите курсор на нужную вершину, дождитесь магнитной подсветки и щёлкните левой кнопкой; для выхода нажмите **Отмена удаления**. В области должно оставаться не менее трёх точек.
4. В поле **Базовая площадь для процентов** выберите всё изображение (по умолчанию) или одну из созданных областей. Проценты отдельных областей, суммы с перекрытиями и объединённой площади рассчитываются относительно выбранной базы.
5. Переименуйте область, выберите её цвет, настройте прозрачность заливки и толщину границы. Справа от каждой шкалы отображается её текущее значение с единицей измерения; при переключении области значение обновляется. Чем выше значение прозрачности, тем слабее видна заливка; настройка применяется сразу и сохраняется после завершения лассо. Толщина границы (1–12 px исходного изображения) также применяется сразу и учитывается при экспорте.
6. Экспортируйте изображение или таблицу Excel при необходимости. Excel содержит выбранную базу и рассчитанные относительно неё проценты.

В верхней панели можно переключить язык интерфейса между русским, сербским (латиница) и английским. Созданные названия областей при переключении не меняются; новые области получают название на текущем языке. Заголовки экспортируемой таблицы Excel соответствуют выбранному языку.

Площадь каждой области рассчитывается в пикселях. «С областями» складывает площади всех областей, поэтому наложения считаются несколько раз. «Без наложений» считает площадь объединения, учитывая повторно покрытые пиксели один раз. Если выбранная область-база имеет нулевую площадь, проценты показываются как «—». Экспорт изображения сохраняет исходные пиксельные размеры и записывает выбранное значение DPI (100, 200, 300, 400, 500 или 600) в метаданные.

Колесо мыши увеличивает или уменьшает изображение относительно положения курсора. Зажмите правую кнопку мыши и двигайте мышь, чтобы перемещать изображение по холсту.
